# 2026-10-14

## 질문
- JSP와 JavaScript는 어떻게 동작하는가?
- WAS 서버는 어떤 역할을 하는가?

## Claude

### 한 줄 요약
JSP는 **서버**에서 실행되어 HTML을 만들고, JavaScript는 그 HTML을 받은 **브라우저**에서 실행된다. WAS는 JSP 같은 서버 프로그램을 실행해 주는 서버다.

### 요청 하나가 처리되는 순서
1. 사용자가 브라우저에서 `list.jsp` 주소를 연다.
2. WAS가 요청을 받아 JSP를 실행한다. 이때 Java 코드가 돌고, 필요하면 DB도 조회한다.
3. 실행 결과로 **HTML 문서(글자)** 가 만들어져 브라우저로 간다. JSP 코드 자체는 브라우저로 가지 않는다.
4. 브라우저가 HTML을 화면에 그리고, 그 안에 있는 JavaScript를 실행한다.
5. 그 뒤 버튼 클릭 같은 반응은 브라우저 안의 JavaScript가 처리한다. 서버의 데이터가 다시 필요하면 서버에 새로 요청을 보낸다 (페이지 이동, 또는 `fetch`/AJAX).

### JSP
- Java Server Pages. HTML 사이에 Java 코드를 섞어 쓰는 **서버 쪽** 기술이다.
- 처음 요청이 오면 WAS가 JSP 파일을 **서블릿(Java 클래스)으로 바꾸고 컴파일**한다. 그다음부터는 컴파일된 것을 바로 실행한다. JSP 파일을 고치면 다시 바꾼다.
- 결과물은 HTML 글자일 뿐이다. 브라우저에서 "페이지 소스 보기"를 하면 JSP 코드는 없고 HTML만 보인다.

### JavaScript
- 브라우저 안에서 실행되는 언어다. (Node.js를 쓰면 서버에서도 돌지만, JSP와 같이 이야기할 때는 보통 브라우저 쪽을 말한다.)
- HTML이 도착한 **뒤에** 실행된다. 화면 요소(DOM)를 바꾸고, 클릭·입력에 반응하고, 서버에 추가 요청을 보낸다.
- 이름이 비슷하지만 Java와는 전혀 다른 언어다.

### 가장 헷갈리는 지점: 실행 순서
```jsp
<% String name = "홍길동"; %>
<script>
  var name = "<%= name %>";
  alert(name);
</script>
```
- 서버에서 JSP가 먼저 실행되어 `<%= name %>` 자리에 `홍길동`이 들어간다.
- 브라우저가 받는 것은 `var name = "홍길동";` 이라는 JavaScript 코드일 뿐이다.
- 그래서 JSP는 JavaScript **코드를 만들어낼** 수는 있지만, 반대로 JavaScript가 JSP 변수를 직접 바꾸거나 JSP 코드를 실행할 수는 없다. 이미 서버에서 실행이 끝났기 때문이다. JavaScript가 서버에 무언가를 시키려면 **새 요청**을 보내야 한다.
- 참고: 실제 코드에서 사용자 입력값을 이렇게 그대로 넣으면 따옴표 때문에 깨지거나 보안 문제(XSS)가 생길 수 있어서, 이스케이프 처리를 한다.

### WAS (Web Application Server)
- 요청이 올 때마다 **프로그램을 실행해서** 응답을 만들어 주는 서버다. 예: Tomcat, JEUS, WebLogic, JBoss(WildFly)
- **웹 서버**(Apache, Nginx)와 비교하면:
  - 웹 서버: 이미 만들어진 파일(HTML, 이미지, CSS, JS)을 그대로 돌려준다 → 정적
  - WAS: JSP·서블릿을 실행해서 상황마다 다른 결과를 만든다 → 동적
- WAS가 하는 일:
  - JSP를 서블릿으로 바꾸고 컴파일해서 실행한다 (이 부분을 "서블릿 컨테이너"라고 부른다)
  - 여러 사람의 요청을 스레드로 나눠 동시에 처리한다
  - 세션을 관리한다 (로그인 상태 유지 등)
  - DB 연결을 미리 만들어 두고 나눠 쓴다 (커넥션 풀)
  - 큰 WAS(JEUS, WebLogic 등)는 트랜잭션 관리 같은 기능도 더 제공한다
- 실무에서는 앞에 웹 서버를 두고, 정적 파일은 웹 서버가, 동적 요청은 WAS가 처리하도록 나누는 경우가 많다.
- Tomcat은 엄밀히는 서블릿 컨테이너지만 보통 WAS라고 부른다. 요즘 Spring Boot는 Tomcat을 안에 내장해서 함께 실행한다.

### 한눈에 비교
| | JSP | JavaScript |
|---|---|---|
| 실행 위치 | 서버 (WAS) | 브라우저 |
| 실행 시점 | 응답을 보내기 전 | 응답을 받은 후 |
| 결과 | HTML 글자 | 화면 변화, 추가 요청 |
| 언어 | Java | JavaScript |
