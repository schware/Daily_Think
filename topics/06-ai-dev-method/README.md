- 이 폴더: **실제로 한 Claude Code 작업**을 사례로 모아, 7원칙이 어떻게 돌았는지 본다.

## 파일

| 파일 | 내용 |
|---|---|

## 7원칙 (한 줄씩)
1. 사람은 Why와 What을 소유한다
2. Claude Code는 How의 탐색과 실행을 맡는다
3. 명세가 구현의 기준이다
4. 생성과 검증을 분리한다
5. 자율성은 위험에 비례한다
6. 프로젝트 지식은 repository에서 관리한다
7. 운영 결과가 최종 피드백이다

## 관리 규칙 (제안)
- 사례 하나 = 파일 하나: `case-NN-<이름>.md`
- 사례마다 같은 순서로 쓴다.
  1. 한 줄 요약과 숫자
  2. 전체 흐름 (실제로 돈 순서)
  3. 7원칙에 대어 보기 (한 것 / 부족한 것)
  4. 검증이 잡은 것, 운영 중에 겪은 것
  5. 다음에 바꿀 것
  6. 근거 (commit, PR)와 참조자료
- 이 repository는 **public**이다. private repository에서 한 작업을 사례로 넣을 때는 repository 이름, server 주소, 업무 내용 같은 세부를 빼고 방식만 적는다.
- 메모는 지금처럼 `index/memo.md`에 원문으로 쌓고 `daily/`에 날짜별로 정리한다. 주제 6에 쌓을 내용만 이 폴더로 옮긴다.
